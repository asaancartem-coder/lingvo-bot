# Telegram-бот с интеграцией LLM для оценки знаний 

Интерактивный образовательный бот, интегрированный с генеративной нейросетью (OpenAI API). Проект автоматизирует диагностику навыков межкультурной коммуникации у пользователей.

 Стек технологий
* **Язык:** Python 3
* **Библиотеки:** pyTelegramBotAPI, Flask, python-dotenv
* **ИИ:** OpenAI API (модель gpt-4o-mini)
* **Инфраструктура:** Render (PaaS), UptimeRobot (мониторинг), CSV (логирование)

## 🚀 Ключевые возможности
* Архитектура пошагового тестирования (32 вопроса/кейса) с динамической генерацией клавиатур и сохранением состояния (State).
* Prompt Engineering: бот автоматически агрегирует данные пользователя и формирует структурированный промпт для анализа.
* Строгий формат вывода ответа от ИИ (Markdown-шаблоны) через настройку System Prompts и параметра temperature.
* Система автоматического логирования результатов в базу (CSV) и отправка отчетов администратору в Telegram.
* Бот обернут во Flask-приложение и задеплоен на облачный сервер для бесперебойной работы 24/7.
